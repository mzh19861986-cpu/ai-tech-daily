## 1. [GET OUT — An AI Assistant That Wants You to Stop Using It](https://dev.to/rohit_itagi_51143896cdd02/get-out-an-ai-assistant-that-wants-you-to-stop-using-it-3jng)

**✨ 精华总结：** 这个叫 GET OUT 的本地 AI 应用反其道而行——不给你聊天机器人或信息流，只问你「有多少时间」和「精力如何」，然后推你去现实世界。它值得关注的地方在于：它把「让用户尽快离开」当作产品目标，是对当前所有追求时长的 AI 应用的一次直接反叛，也是「AI 应该服务人而非占用人的注意力」这个被反复讨论却极少被真正落地的问题的一次具体尝试。

## 2. [Touch Grass - AI outdoor companion](https://dev.to/yogesh147/touch-grass-ai-outdoor-companion-5a1n)

**✨ 精华总结：** 一款叫 Touch Grass 的 AI 户外助手，用 Gemma 模型根据你手头有多少时间，生成一个简短的户外小任务——比如“出门待 3 分钟”——然后鼓励你把手机收起来真正走出去。它用 Python 写了后端 API 连接前端和数据，还支持离线 demo 模式。有意思的点在于：它反其道而行，把 AI 用在让你少刷手机上。

## 3. [Robots.txt Deep Dive: What It Can and Cannot Do](https://dev.to/marketingwithanosh/robotstxt-deep-dive-what-it-can-and-cannot-do-1bn7)

**✨ 精华总结：** Robots.txt 只控制爬虫的抓取行为，不是用来屏蔽页面出现在搜索结果里的。很多人把它当成访问控制工具，结果要么误封整站，要么以为写了 `Disallow` 内容就不会被收录。

## 4. [Build a Slack Bot That Investigates Any IP You Paste](https://dev.to/abdullah_afzal/build-a-slack-bot-that-investigates-any-ip-you-paste-5gml)

**✨ 精华总结：** 想让 Slack 机器人查 IP 不稀奇，稀奇的是它顺手把「该找谁投诉」也解决了。大多数人查完 IP 归属和风险评分就收工，但真正能阻断滥用行为的 abuse 联系邮箱往往藏在 WHOIS 和 RIR 记录里——需要额外一次查询、人工读记录、还得猜哪个字段才是联系人。这个项目的价值就在把这最后一步自动化了，让举报链路真正闭合。
