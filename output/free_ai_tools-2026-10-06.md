## 1. [Beam: Reflection's 501B open-weight model](https://reflection.ai/blog/introducing-beam)

**👥 适合谁：** 这款 AI 工具最适合**独立开发者与低成本研究团队**——他们需要用可自行部署、可微调的开源权重模型来搭建定制化应用，同时又不愿承担闭源大模型的 API 成本和数据外泄风险。

**🚀 怎么开始：** 直接打开 Reflection 的官网或 Hugging Face 页面就能在线体验 Beam 501B，也可以下载开放权重在本地部署；若要调用 API，则需要申请对应的访问密钥。

**📝 简介：** Beam 是 Reflection 发布的一个 501B 参数的开源权重模型，规模在当前开放模型中属于第一梯队。值得关注的点在于：它以开放权重形式放出，意味着研究者和开发者可以自行部署、微调，而不必依赖闭源 API——这对想掌控模型自主权、又需要顶级性能的团队来说是个实质性选项。

## 2. [Dust: Pretraining Transformers Without Backpropagation](https://qlabs.sh/research/dust)

**👥 适合谁：** 最适合**研究高效训练方法的高校实验室与AI研究员**使用。

**🚀 怎么开始：** Dust 是一个研究型 Transformer 预训练项目，需要下载代码仓库、配置 Python 环境（含 PyTorch 等依赖），并在本地或集群上运行训练脚本，无法直接在网页端开箱即用。

**📝 简介：** 传统 Transformer 训练依赖反向传播，而 Dust 提出了一种无需反向传播的预训练方法。它的核心价值在于绕开了反向传播对显存和计算图的强依赖，可能让大模型训练变得更省资源、更容易并行。如果你关注训练效率或想摆脱 BP 的束缚，这个方向值得盯一下。
