## 2. [Dust: Pretraining Transformers Without Backpropagation](https://qlabs.sh/research/dust)

**👥 适合谁：** 最适合**研究新型神经网络训练方法的高校科研人员和AI算法研究者**使用。

**🚀 怎么开始：** 直接打开网页就能看论文和代码，无需 API key 或本地部署；想跑实验的话，克隆 GitHub 仓库按 README 安装依赖即可。

**📝 简介：** 一种叫 Dust 的新方法，能在**完全不使用反向传播**的情况下预训练 Transformer 模型。反向传播是当前所有主流大模型训练的核心机制，但它计算和显存开销大、且被认为不太符合生物大脑的学习方式——Dust 绕开它，意味着训练大模型可能有了更省资源、甚至更接近大脑原理的另一条路径。
