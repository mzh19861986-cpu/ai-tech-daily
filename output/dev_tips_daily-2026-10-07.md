## 技巧 2

**Node.js Security Best Practices: Build Safer and More Resilient APIs**

✨ Node.js 官方发布了一份 API 安全实践指南，核心思路是「纵深防御」——在输入验证、安全响应头、限流、依赖管理等每一层都设置独立防线，而不是指望单一措施兜底。如果你在用 Node.js 跑生产级 API，这份清单值得对着自查一遍，毕竟它处理的是认证令牌、用户输入和数据库查询这些最容易出事的地方。
