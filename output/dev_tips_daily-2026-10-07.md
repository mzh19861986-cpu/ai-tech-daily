**Retrieval-Augmented Large Language Model Decision-Making for Autonomous Driving Guided by Chinese Philosophical Wisdom**

✨ 这篇论文给自动驾驶决策系统引入了一个有意思的视角：用中国哲学智慧（比如中庸、无为等思想）来指导大语言模型做驾驶决策，试图在安全、效率和社会规范之间找到更好的平衡。目前主流的自动驾驶决策方法——无论是数值优化、序列预测还是普通LLM——基本只关注能不能算得准、跑得快，很少认真处理"什么样的驾驶行为才算得体"这种带伦理色彩的问题。这个思路如果真能落地，可能让自动驾驶在复杂路况下的表现更接近"懂分寸"的人类司机，而不只是冷冰冰地避障。

## 技巧 3

**Claude Code vs Codex CLI vs Cursor: An Honest Field Guide for Working Developers**

✨ 这篇实战对比来自一位三款工具都在日常使用的开发者，核心结论是：它们不是替代关系，而是三种不同的“思维方式”，选错了会实打实浪费时间。Claude Code 偏终端里的自主执行、Codex CLI 强在精准的代码生成与命令编排、Cursor 则是编辑器内的沉浸式协作，作者还把逐行核对过的命令、快捷键和配置整理成了一个速查仓库。值得关注的是它给出了“什么任务配什么工具”的判断依据，而不是又一篇参数罗列。
