# ⚡ 3 分钟 AI 快讯 - 2026-10-06

> 每天 3 条最重要的 AI 新闻，3 分钟看完

**1. Sharing AI Progress in Mathematics**

   微软研究院发布了一个专门展示AI在数学领域进展的页面，汇集了他们在形式化证明、定理发现等方面的最新成果。值得关注的是，这背后是AI从「算得快」走向「推得对」的关键转变——数学证明对逻辑严密性要求极高，能在这里取得突破，意味着AI的推理能力正在逼近真正的严谨思维。

**2. Mistral Large 4**

   Mistral 发布了 Large 4，最新一代旗舰大模型，主打推理能力和多语言性能的进一步提升。如果你在关注开源权重模型能不能追上闭源第一梯队，这次更新值得留意——它在多个基准上对标 GPT-4o 和 Claude 级别，同时保持了 Mistral 一贯的部署灵活性。

**3. Decisions API is in public beta**

   Vercel 把它的 Decisions API 开放公测了——这是一套让开发者能在应用里直接接入“决策”能力的接口，比如根据用户特征或上下文动态判断该走哪条逻辑分支。值得关注是因为它把过去要自己搭规则引擎或 A/B 测试基建的活儿，变成了一个开箱即用的 API 调用，特别适合需要频繁调整策略又不想反复发版的场景。
