**1. Sharing AI progress in mathematics**

   这应该是DeepMind关于用AI推进数学研究的最新进展——他们让AI在数学证明和猜想发现上做出了实质性贡献，比如帮助数学家发现了新的数学结构或简化了复杂证明。这事值得关注，因为数学一直被视为人类智能的「高地」，AI能在这里拿出真东西，意味着它不再只是模式匹配工具，而是开始具备某种程度的创造性推理能力了。

**2. Mistral Large 4**

   Mistral AI 发布了 Mistral Large 4，这是他们最新的旗舰大模型。值得关注的是它在推理、多语言和代码任务上的性能进一步提升，同时保持了 Mistral 一贯的高效架构路线，意味着用更低的推理成本就能获得接近头部闭源模型的效果。

**3. Decisions API is in public beta**

   GitHub 把 Decisions API 开放公测了，现在你可以用代码直接查询和操作仓库里的规则集、分支保护这些决策逻辑，不用再手动翻设置页。对做合规审计或大规模仓库管理的团队来说，这意味着终于能把「谁在什么条件下能合并代码」这件事自动化，而不是每次靠人肉检查。
