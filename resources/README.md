# 资源库

本目录按类别整理 AI Agent 被动收益自动化所需的全部参考资源。

## 文件索引

| 文件 | 内容 |
|------|------|
| [reference-projects.md](./reference-projects.md) | 同类开源项目 / 成功案例 |
| [tools.md](./tools.md) | 技术工具链（爬虫、AI、部署、数据库） |
| [platforms.md](./platforms.md) | 可变现平台清单（广告、支付、数字产品） |
| [apis.md](./apis.md) | 可用免费/低成本 API |
| [compliance.md](./compliance.md) | 合规红线与禁止事项 |

## 使用方式

1. 先读 `compliance.md`，划清能做和不能做的边界
2. 从 `reference-projects.md` 找可 fork 的起点
3. 用 `tools.md` 和 `apis.md` 组装技术栈
4. 对照 `platforms.md` 选变现通道
